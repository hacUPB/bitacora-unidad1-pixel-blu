
1 El encapsulamiento es una forma de proteger la información de una clase para que no pueda ser modificada directamente de cualquier manera. En lugar de acceder a todo directamente, se utilizan métodos para controlar cómo se puede consultar o cambiar esa información.

2 La herencia permite que una clase pueda tomar características y funciones de otra clase. Esto sirve para no tener que escribir el mismo código varias veces y para organizar mejor un programa.

3 polimorfismo significa que una misma función puede comportarse de diferentes maneras dependiendo del objeto que la utilice.
